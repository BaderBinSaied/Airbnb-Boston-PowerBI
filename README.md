
# Boston Airbnb | Power BI Dashboard

An interactive Power BI dashboard analyzing Airbnb property listings in Boston, USA.

## Overview
This project explores property distribution, nightly prices, guest reviews, and host information using historical Airbnb data collected in September 2016.

## Dashboard Pages
- Properties
- Prices
- Reviews
- Hosts
- Info

## Tools Used
- Power BI
- Power Query
- DAX

## Data Source
[Boston Airbnb Open Data - Kaggle](https://www.kaggle.com/datasets/airbnb/boston)
